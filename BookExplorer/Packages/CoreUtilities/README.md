
# CoreUtilities

## Purpose
Provides reusable helper functions, extensions, and utilities to support Core and feature modules.  
Ensures common code is centralized and reduces duplication.

## Responsibilities
- Swift extensions (String, Date, Array, etc.)
- Common helper classes and structs
- Shared constants, enums, and value objects
- Utility functions for async operations, formatting, and validation

## Usage
- Import CoreUtilities wherever shared functionality is needed
- Helps maintain DRY principle across the project

## Notes
- This module should **never contain feature-specific logic**
- Keep it lightweight and focused on reusability
